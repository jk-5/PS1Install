## PowerShell Multi Installer 🛠️

![PowerShell](https://img.shields.io/badge/PowerShell-%235391FE.svg?style=for-the-badge&logo=powershell&logoColor=white)
![Windows](https://img.shields.io/badge/Windows-0078D6?style=for-the-badge&logo=windows&logoColor=white)

**PowerShell Multi Installer** to kompleksowe narzędzie automatyzujące proces przygotowania systemu Windows do pracy. Pozwala na szybką instalację niezbędnego oprogramowania, zarządzanie aktualizacjami oraz optymalizację konfiguracji systemowej za pomocą jednego polecenia.

## 🌟 Główne funkcje

- **Automatyczna instalacja**: Szybki wybór i instalacja najpopularniejszych programów.
- **Zarządzanie aktualizacjami**: Sprawdzanie dostępności poprawek systemowych i ich szybka aplikacja.
- **Konfiguracja systemu**: Optymalizacja ustawień Windows, usuwanie zbędnych elementów i dostosowanie interfejsu.
- **Bezobsługowość**: Oszczędność czasu dzięki automatyzacji procesów.

## 🚀 Szybki start

Nie musisz niczego pobierać ręcznie. Narzędzie można uruchomić bezpośrednio z konsoli PowerShell.

### Jak uruchomić?

1. Kliknij prawym przyciskiem myszy na przycisk **Start** (logo Windows).
2. Wybierz z listy **Terminal (Administrator)** lub **Windows PowerShell (Administrator)**. 
   > *Ważne: Skrypt wymaga uprawnień administratora do instalacji programów i zmiany ustawień systemowych.*
3. Skopiuj poniższe polecenie, wklej do konsoli i naciśnij **Enter**:

```powershell
irm https://raw.githubusercontent.com/jk-5/PS1Install/main/MultiInstall.ps1 | iex

```
